# 大老二 Online

2~4 人的線上大老二對戰。可開房、用房號加入、觀戰，大廳與房間各有獨立聊天室。
伺服器持有權威狀態，所有出牌都在後端驗證過才算數。

## 快速開始

```bash
npm install
npm run dev
```

開 http://localhost:5173 ，輸入暱稱就能開房。
**要多開幾個玩家，直接開新分頁即可** —— 身分存在 `sessionStorage`，每個分頁是獨立玩家，
但重新整理（F5）還是同一個人，會接回原本的座位與手牌。

| 指令 | 用途 |
| --- | --- |
| `npm run dev` | 同時啟動後端 (3001) 與前端 dev server (5173) |
| `npm test` | 規則引擎與遊戲流程的單元測試 |
| `npm run typecheck` | 三個套件的型別檢查 |
| `npm run build` | 打包前端到 `client/dist` |
| `npm run serve` | 打包後用單一服務跑在 `0.0.0.0:80` |

## 開在區網 / 換連接埠

`npm run serve` 會先打包前端，再讓後端綁 `0.0.0.0:80`，同一個網址就同時提供 API 與前端。
啟動時會把可用的區網位址印出來，直接把 `http://192.168.x.x` 給同網段的人就能連。

連接埠與網卡都可以改，命令列參數優先於環境變數：

```bash
npm start -w server -- --port 8080        # 換埠
npm start -w server -- --host 127.0.0.1   # 只開放本機
npm run dev -w client -- --port 80        # dev server 也可以換埠（Vite 原生旗標）
```

只要 `client/dist` 存在，後端就會一併吐出前端；沒打包過就只有 API，前端請走 `npm run dev`。

> Windows 的 80 埠常被 IIS 或 http.sys 占著。若出現 `EADDRINUSE` 就換一個埠，
> `EACCES` 則需要用系統管理員身分執行。

## 規則

**牌組**　52 張。點數 `3 < 4 < … < K < A < 2`，花色 `♦ < ♣ < ♥ < ♠`。

**發牌**　不論 2/3/4 人都是每人 13 張，剩下的牌本局不用。
持有最小牌的人先手，且第一手必須包含那張牌（4 人局固定是 ♦3）。

**牌型**

| 張數 | 牌型 | 比大小 |
| --- | --- | --- |
| 1 | 單張 | 點數 → 花色 |
| 2 | 對子 | 點數 → 較大花色 |
| 3 | 三條 | 點數 |
| 5 | 順子 | 最大張點數 → 花色 |
| 5 | 同花 | 最大張點數 → 花色 |
| 5 | 葫蘆 | 三條的點數 |
| 5 | 鐵支 | 四張的點數 |
| 5 | 同花順 | 最大張點數 → 花色 |

五張牌型之間：`順子 < 同花 < 葫蘆 < 鐵支 < 同花順`。
順子範圍是 `3-4-5-6-7` 到 `10-J-Q-K-A`，再加最大的 `J-Q-K-A-2`；不接受 `A-2-3-4-5` 這種跨頭順。

**回合**　跟牌必須同張數。其他人全部 PASS 後，最後出牌的人取得領牌權，可自由出牌；
領牌者不能 PASS。每回合 45 秒，逾時自動 PASS（有領牌權時自動出最小的一組）。

**結束**　手牌先出完的人名次在前，剩最後一人時本局結束。不計分，房主可直接開下一局。

**觀戰**　觀戰者是上帝視角，看得到所有人的手牌。
這代表玩家可以自己開第二個分頁觀戰自己那局 —— 想防的話再加「房間密碼／房主可關閉觀戰」即可。

## 架構

```
shared/   規則引擎與型別，前後端共用同一份（零依賴的純 TS）
server/   Express + Socket.IO，房間與遊戲狀態都在記憶體
client/   Vite + React + TypeScript
```

核心是 `shared/src/combos.ts`：`identifyCombo` / `canBeat` / `smallestLegalPlay`。
伺服器用它做權威判定，前端用**同一份程式碼**即時決定「出牌」按鈕能不能按、
以及「提示」要選哪幾張，所以規則不會前後端各寫一套而走鐘。

**狀態同步**　任何變更後由伺服器重算並推送完整快照，前端不做樂觀更新。
`room:state` 是為每個連線各自產生的：玩家只拿得到自己的手牌，其他人只有剩牌數；
觀戰者才拿得到 `allHands`。

**斷線**　socket 斷掉只標記離線並保留座位與手牌 30 秒，同一個 `playerId` 重連就無縫接回。
離線期間輪到他時 3 秒後代打，不讓整桌乾等；超過 30 秒才真的移出房間。
房主離開時 host 自動轉給下一位在座玩家，房間空了就解散。
